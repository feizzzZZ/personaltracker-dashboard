# Finance OS — Personal Finance Dashboard

Personal finance tracker and investment dashboard built with vanilla HTML/JS.

## Features
- 📊 Cash Flow (Monthly & Yearly)
- 🏦 Accounts & Bank Balances
- 💼 Investment Holdings (Asset_Tracker based)
- 🛡 Insurance Dashboard
- 💰 Budget Alert with Sidebar Badge
- 📈 Benchmark Comparison (SET, S&P 500, Gold, Crypto)
- 🎯 Financial Goals Tracker
- 📄 Monthly Report PDF Export
- 🔔 Budget Notification

## How to use
1. Open `index.html` (or visit the GitHub Pages URL)
2. Upload your Excel file (`.xlsx`)
3. Required sheets: `Transaction`, `Asset_Tracker`, `Asset_Dashboard`, `Asset_Live_Price_Feed`
4. Optional sheets: `Insurance_Policies`, `Insurance_Coverage`
