## ส่วนที่ 2 — สิ่งที่ต้องทำเอง (แก้ในโค้ดไม่ได้)

1. **ประวัติพอร์ตเก่าใน git ยังอ่านได้** — การเข้ารหัสมีผลตั้งแต่รอบถัดไป แต่ commit เก่าของ `notify-state.json` ยังอยู่
   ทางเลือก: ตั้ง repo เป็น Private (GitHub Pages ฟรีต้อง public → ใช้ Cloudflare Pages/Netlify แทน) หรือ
   ล้างประวัติไฟล์นั้นด้วย `git filter-repo --path notify-state.json --invert-paths` แล้ว force push
2. **log ของ Actions เป็นสาธารณะ** — โหมด `check` และ `dry_run` ของ Notify พิมพ์มูลค่าพอร์ตรายตัวลง log · ใช้สองโหมดนี้เฉพาะตอนจำเป็น แล้วลบ run นั้นทิ้ง
3. `market-data.json` / `fundamentals.json` บอกว่าถือหุ้นตัวไหน (ไม่มีจำนวน/มูลค่า) — ยอมรับได้ถ้า repo ยังสาธารณะ
4. ต้องมี secret `NOTIFY_KEY` ใน workflow Notify (มีอยู่แล้วถ้าใช้แจ้งเตือนในแอป) ไม่งั้นไฟล์ยังเขียนแบบเดิม

## ส่วนที่ 3 — UX/UI จากการใช้งานจริง (ยังไม่ได้แก้ · เรียงตามผลกระทบ)

**ภาพรวม**
- "ต้องลงมือ" บนเดสก์ท็อปแสดงครบ 9–10 เรื่องยาวทั้งก้อน (มือถือย่อเหลือ 2) → ใช้แบบย่อทั้งสองขนาด แสดง 3 เรื่องแรก
- ไทล์ "ตลาด: ปกติ" สีเขียว ขณะที่กล่องเดียวกันเตือนแดงว่าข้อมูลตลาดเก่า 3 วัน → ข้อมูลเก่าควรทำให้ไทล์เป็นสีเตือน
- % เป้าหมายมีสองตัว (หน้าเป้าหมาย 13% = ช่วง ฿1M→฿2M · Overview 37.6% = ของ ฿3M) อ่านแล้วงง → ใส่ป้ายกำกับให้ชัดว่าเทียบกับอะไร

**เงินเข้า-ออก / งบ**
- หน้างบ: การ์ด 21 ใบเรียงตามตัวอักษร รวมหมวดตั้งต้นส่วนตัวที่ไม่เคยใช้ (Dtac (Mom), Motocycle) → เรียง เกิน → ใกล้เกิน → ปกติ และพับหมวดที่ใช้ ฿0
- งบตั้งเป็น 0 ไม่ได้ (กลับไปใช้ค่าตั้งต้น) → ต้องมี "ไม่ตั้งงบหมวดนี้"
- หน้างบไม่มีตัวเลือกเดือนของตัวเอง (ใช้เดือนที่เลือกไว้ในหน้ารายเดือน) → ใส่ตัวเลือกเดือนแบบเดียวกัน
- โดนัท "Expense breakdown" และกราฟรายวันไม่นับรายจ่ายที่รูดบัตร (แถว Debt) ขณะที่หน้างบนับ → ตัวเลขสองหน้าไม่ตรงกัน
- ตารางธุรกรรม 15 แถว/หน้า ไม่มีช่องค้นหา/กรองหมวด
- การ์ด "DEBT" ปนยอดรูดบัตรกับค่างวดสินเชื่อ → แยกเป็นสองตัวเลข (มี `debtSplit` อยู่แล้วในหน้ารายปี)

**บัญชี & หนี้**
- ตารางดอกเบี้ยบนมือถือ: ช่องกรอก % ดอกเบี้ย (สิ่งที่ต้องทำ) หลุดขอบขวา ต้องเลื่อนตารางถึงเห็น → จัดเป็นการ์ดบนมือถือ
- บทสรุป "จ่ายหนี้ก่อน" ชูหนี้ ฿1,357 ที่ใส่ดอกเบี้ยแล้ว ขณะที่หนี้ก้อนใหญ่ ฿207,000 ยังไม่มีดอกเบี้ย → ขอ APR ของก้อนใหญ่ก่อน
- ย่อหน้าอธิบายเดียวกันซ้ำใต้ทุกบัญชีในบล็อก "หนี้ก้อนนี้มาจากอะไร" → แสดงครั้งเดียว
- กราฟยอดสิ้นปีมีแค่ 2 จุดเมื่อข้อมูลไม่ถึง 2 ปี → ใช้รายเดือน

**พอร์ต / ปันผล**
- "Where are your assets" กับ "Asset investment location" แสดงข้อมูลแพลตฟอร์มซ้ำกัน → รวมเหลืออันเดียว
- ปันผลมี Yield สองตัว (0.83% คาดการณ์ · 0.24% ย้อนหลัง) ป้ายใกล้กันมาก
- กราฟปันผลรายเดือนข้ามเดือนที่ไม่มีปันผล (แท่งเรียงติดกัน) → เติมเดือนว่างให้เห็นจังหวะจริง
- ตารางสัญญาณบนมือถือต้องเลื่อนข้าง คอลัมน์สำคัญ (สรุป) อยู่ขวาสุด

**ทั่วทั้งแอป**
- หลายหน้ามีคำอธิบายแนวบันทึกการพัฒนา (เช่นหน้าตลาด "v44 ปิดการให้คะแนนไปเพราะ…", คำอธิบายเกณฑ์สัญญาณยาวหลายย่อหน้า) → ย้ายไปไว้ใน "ⓘ อ่านเพิ่ม" ที่พับไว้
- ปุ่ม/ป้ายปนไทย-อังกฤษในหน้าเดียวกัน (Edit/Delete/Add new goal · Holdings · Budget)
- ฟอร์มเพิ่มรายการกด Esc ปิดไม่ได้ (ฟอร์มเอกสารปิดได้)
- เป้าหมายแบบจำนวนเงินต้องกรอก "เก็บแล้ว" เองทุกครั้ง → ผูกกับยอดบัญชี/กลุ่มสินทรัพย์ได้จะอัปเดตเอง
