## ข้อมูลที่ยังขาด / ต้องแก้นอกแอป (ไม่ได้แก้ในรุ่นนี้ — รอตัดสินใจ)

1. **หนี้ผ่อน (ค่างวด/ยืมคนในครอบครัว) ไม่มียอดคงค้างในชีต** — แอปเห็นแค่ค่างวดรายเดือน
   Net Worth จึงสูงกว่าจริงเท่ายอดคงค้าง และหน้าหนี้/แผนปลดหนี้ครอบคลุมแค่บัตรเครดิต
   ทางที่แอปรองรับแล้ว (ทดสอบใน v62): เพิ่มคอลัมน์บัญชีในชีต Transaction ประเภท `Loan #` ใส่ยอดคงค้างติดลบ
   แล้วบันทึกค่างวดแบบเดียวกับ "Clear Debt" (ธนาคาร −X / คอลัมน์หนี้ +X)
   — ผลข้างเคียง: เงินต้นที่จ่ายจะไม่ถูกนับเป็นรายจ่ายอีก saving rate จะสูงขึ้น (ถูกต้องตามหลักบัญชี)
2. **Apps Script ที่เขียน Value_Log** — วันธรรมดาราคาหุ้นไทย+ทองหลุด และหยุดเขียนตั้งแต่ต้นเดือนกันยายน
   (สคริปต์ไม่อยู่ใน repo) · แก้ได้โดยให้สคริปต์ใช้ราคาจาก `market-data.json` เหมือนแอป · แก้แล้วลบแถวเก่าที่กระโดดออก
3. **กรมธรรม์ที่จ่ายรายเดือนหลายฉบับไม่มี Renewal_Date** — แอปเตือนก่อนครบกำหนดไม่ได้
4. **งบประมาณไม่นับรายจ่ายที่รูดบัตร** (แถว Debt) — ถ้าอยากให้เข้างบ ให้พิมพ์แถวรูดบัตรเป็น `Expense`
   พร้อมหมวดจริงแต่ยังใส่ยอดในคอลัมน์บัตร (ยอดบัตร/ยอดหนี้/saving rate ไม่เปลี่ยน)
