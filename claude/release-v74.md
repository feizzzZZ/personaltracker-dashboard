โจทย์: ปรับธีมให้มีทั้ง light และ dark · หน้าเว็บให้ใกล้เคียง Midday (ภาพอ้างอิง 3 ภาพ: dashboard · login · ตารางธุรกรรม) ·

## 2. เข้าสู่ระบบ

หน้าใหม่แบบ Midday (ภาพนามธรรมขาวดำด้านซ้ายสร้างด้วย SVG `feTurbulence` · ไม่มีไฟล์ภาพ)

| สถานะเครื่อง | ปุ่มหลัก | ทางสำรอง ("ตัวเลือกอื่น") |
|---|---|---|
| ยังไม่มีบัญชี | เข้าสู่ระบบด้วย Google | สร้างบัญชีในเครื่องนี้ (ชื่อผู้ใช้ + รหัสผ่าน) · ตั้งค่า Sheets |
| มีบัญชีแล้ว | ชื่อผู้ใช้ + รหัสผ่าน → ปลดล็อก | เข้าด้วย Google · ตั้งค่า Sheets · ลืมรหัสผ่าน |

**ไม่มี server** — "บัญชี" อยู่ในเครื่องนั้นเครื่องเดียว (ข้ามเครื่องใช้ Google) หน้าที่คือล็อกแอป + เข้ารหัสสิ่งที่เก็บในเครื่อง

`vault.js` (ไฟล์ใหม่ · เทสต์ `scripts/test_vault.cjs` 36 ข้อ)
- PBKDF2-SHA256 600,000 รอบ + salt สุ่ม 16 ไบต์ → กุญแจ AES-GCM 256 · ไม่เก็บรหัสผ่าน เก็บแค่ salt + ข้อความตรวจที่เข้ารหัส
- เข้ารหัส: cache ข้อมูล (`finOS_dataCache` ~0.3–1 MB) + token Google → `finOS_enc:*` · ลบฉบับข้อความธรรมดาทิ้ง
- ใส่ผิด 5 ครั้ง → รอ 30 วิ แล้วเพิ่มเท่าตัว (สูงสุด 15 นาที) · ไม่บอกว่าผิดช่องชื่อหรือรหัส
- รีโหลดในแท็บเดิมไม่ต้องใส่รหัสใหม่ (กุญแจใน `sessionStorage`) · ปิดแท็บ/ปิดแอป = ล็อก
- ล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน (ค่าเริ่มต้น 15 นาที · ตั้ง 5/15/30/60/ไม่ล็อกได้) · ล็อก = รีโหลดหน้า → ล้างข้อมูลในหน่วยความจำแน่นอน
- ช่องกรอกมี `autocomplete="username"/"current-password"/"new-password"` → ตัวจัดการรหัสผ่านของเบราว์เซอร์/iCloud Keychain จำให้ได้
- ลืมรหัส = ล้างบัญชี + ข้อมูลในเครื่อง → เข้าด้วย Google ใหม่ (ข้อมูลจริงอยู่ในชีต ไม่หาย)
- เข้าด้วย Google ขณะเครื่องล็อกอยู่ได้ (Google พิสูจน์ความเป็นเจ้าของชีตอยู่แล้ว) แต่ไม่มีกุญแจ → ไม่เก็บอะไรลงเครื่อง + มีแถบบอก

บัญชีและความปลอดภัย (เมนูบัญชี / ⌘K): ตั้ง/เปลี่ยน/เลิกใช้รหัสผ่าน · ล็อกอัตโนมัติ · บัญชี Google ที่เชื่อม · ออกจากระบบ ·
ตาราง "สิ่งที่เก็บในเครื่องนี้" บอกตรง ๆ ว่าอะไรเข้ารหัส อะไรไม่ · หลัง sync ครั้งแรกโดยยังไม่มีรหัสผ่าน มีแถบชวนตั้ง (ครั้งเดียว)

## 3. Google เสถียรขึ้น

| ปัญหาเดิม | แก้ |
|---|---|
| ต่ออายุ token แบบเงียบสำเร็จแต่ไม่บันทึก → รีโหลดหน้าแล้วต้องต่ออายุซ้ำทุกครั้ง | `gsSaveToken()` ทุกครั้งที่ได้ token |
| มีหลายบัญชี Google ในเบราว์เซอร์ → ต่ออายุเงียบต้องเลือกบัญชี → ล้ม | `login_hint` = อีเมลที่เคยใช้ (ขอสิทธิ์ `email profile` เพิ่มเฉพาะตอนผู้ใช้กดเอง) |
| ผู้ใช้ไม่ติ๊กสิทธิ์ Sheets ในหน้ายินยอม (granular consent) → sync 403 ตลอดไม่รู้สาเหตุ | ตรวจ `hasGrantedAllScopes` แล้วบอกว่าต้องติ๊กช่องไหน |
| popup ถูกบล็อก → กล่อง "ไม่สำเร็จ" ที่ไม่บอกอะไร | บอกให้อนุญาต pop-up |
| ต่ออายุเงียบล้มแล้วไม่เรียก callback → ผู้เรียกรอค้าง | เรียก `cb(false)` |
| เปิดแอปใหม่ทุกครั้งขอ `consent` ซ้ำ (ดู `gsConnected` ที่ false เสมอตอนเปิด) | เคยยินยอมแล้ว (`gs_ever_connected`) → `prompt:''` |
| ไม่มีทางออกจากระบบ | เมนูบัญชี → ออกจากระบบ (revoke token + ล้าง cache) |
| ปลดล็อก → ขอ token | ทำในจังหวะที่ผู้ใช้เพิ่งกด (popup ไม่โดนบล็อก) |

`gsInit()` เป็น async แล้ว (ถอด cache/token ที่เข้ารหัส) · ล็อกอยู่ = ไม่ init/sync/visibilitychange-sync จนกว่าจะปลดล็อก

## ตรวจแล้ว

- เทสต์ JS 11 ชุดผ่าน (รวม `test_vault.cjs` ใหม่) · Python ผ่านบน 3.12 (2 ชุดที่ต้องใช้ `cryptography` ไม่ได้รัน — เครื่องไม่มีแพ็กเกจ)
- เบราว์เซอร์จริง (localhost + ข้อมูลจำลอง): ป้อนข้อมูล → สร้างบัญชีจากเมนู → cache กลายเป็นเข้ารหัส (ไม่มีข้อความ `txRows`) ·
  รีโหลดแท็บเดิม → ข้อมูลกลับมา 942 แถว · ล็อก → ข้อมูลในหน่วยความจำ 0 · รหัสผิด → ขึ้นข้อความ · รหัสถูก → กลับมาครบ ·
  ไม่ใช้งาน 16 นาที → ล็อกเอง · กด Google ตอนล็อก (ยังไม่ตั้งค่า Sheets) → หน้าต่างตั้งค่าขึ้นทับ ·
  กด Google แล้วยกเลิก → ปลดล็อกด้วยรหัส → cache ยังถอดได้ (บั๊กที่เจอระหว่างทดสอบ แก้แล้ว)
- ภาพหน้าจอ: login (welcome/unlock · light/dark · มือถือ) · ภาพรวม · Cash Flow · งบ · พอร์ต · เมนูบัญชี · ⌘K · หน้าต่างบัญชี
- 24 หน้า × 1440/500px ไม่มี JS error

**ยังไม่ได้ทดสอบกับ Google จริง** (ต้องใช้ Client ID + บัญชีของคุณ) — ลองครั้งแรกหลัง deploy:
Google จะถามสิทธิ์ "ดูอีเมล" เพิ่ม 1 ครั้ง (ใช้แสดงชื่อบัญชีและช่วยให้ต่ออายุเงียบเลือกบัญชีถูก)

### True Performance — ใหม่

เดิม: XIRR / TWR / เงินเข้าออก เป็น % สามตัวที่ไม่มีอะไรให้เทียบ · เครื่องยนต์/ตัวถ่วงเรียงตาม %/ปี

ตอนนี้ตอบ 3 คำถาม:
1. **ลงทุนแล้วได้มากกว่าฝากธนาคารเท่าไร (บาท)** — เอา cashflow ชุดเดิม (เข้า-ออกวันเดียวกัน) ไปคิดที่ฝากประจำ 1.5%/ปี (ค่าสมมติ กด "แก้" ได้ · เก็บใน `finOS_depositRate`)
   และที่อัตราเงินเฟ้อ (`TH_CPI`) → แท่งเทียบ 3 แท่ง: พอร์ตวันนี้ · ถ้าฝากธนาคาร · ถ้าแค่ตามเงินเฟ้อ
2. **กำไรมาจากไหน** — เรียงตามกำไรเป็นบาท + % ของกำไรรวม · บอกถ้ากำไร > 60% มาจาก 3 ตัว (พึ่งไม่กี่ตัว)
3. **ตัวไหนแพ้ฝากธนาคาร** — ได้น้อยกว่าเอาเงินก้อนเดียวกันไปฝากกี่บาท · รวมเป็นกี่ % ของพอร์ต (ถือไม่ถึง 3 เดือนยังไม่ตัดสิน)

แก้ตัวเลขที่ทำให้เข้าใจผิด:
- **TWR**: ไม่ถึง 1 ปี → แสดงผลสะสม ("−3.01% ใน 74 วัน") ไม่แปลงเป็น %/ปี (มาตรฐาน GIPS) · เดิมตัดที่ 30 วัน → 60 วัน +23% กลายเป็น "+248%/ปี"
- **รายตัว**: ถือไม่ถึง 1 ปี → "+12% · ถือ 3 เดือน" แทน %/ปี · เดิมตัวที่เพิ่งซื้อแล้วขึ้นนิดหน่อยถูก annualize ขึ้นอันดับ 1
- ครบ 1 ปีแล้ว TWR เทียบ XIRR บอกว่าจังหวะเติมเงินช่วยหรือถ่วง

`shared.js`: `flowsFutureValue` · `holdingPerf` · `twrView` · `DEPOSIT_RATE_DEFAULT` — เทสต์ `scripts/test_perf.cjs` 19 ข้อ
(รวมข้อที่ว่า "ฝากที่อัตรา = XIRR ต้องได้มูลค่าเท่าพอร์ตพอดี" ยืนยันว่าสูตรเทียบสอดคล้องกับ XIRR)

**Analyst ใช้ `holdingPerf` แล้ว** (เดิมยังใช้ XIRR รายตัว → ถือ 3 เดือนขึ้น 12% กลายเป็น ≈ +57%/ปี):
- `buildAnalystCtx()` สร้าง `perAsset` ด้วย `holdingPerf(flows, val, now, perfDepositRate())` แทน `xirrJS` รายตัว
- `analystPortfolio` ข้อ "ตัวถ่วงที่ใหญ่พอจะสำคัญ": เดิม XIRR < −10%/ปี → ตอนนี้ แพ้ฝากธนาคาร ≥ 5% ของเงินที่ใส่ · ถือ ≥ 3 เดือน · > 3% ของพอร์ต
