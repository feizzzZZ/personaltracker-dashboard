# v75 — บอทเทรดตามกฎ (เฟส 1: paper)

คำขอ: "สร้างบอทเทรดอัตโนมัติ เป็นเมนูใหม่ใต้พอร์ตลงทุน ตั้งคำสั่งแล้วให้บอทเทรดกับแอปลงทุนภายนอก"
ผู้ใช้เลือก: Binance · หุ้นไทยผ่าน Settrade Open API · Dime/Streaming · **ทดลองแบบ paper ก่อน** · รันบน **Cloudflare Worker**

## เฟสนี้ทำอะไร

**ไม่มีการส่งคำสั่งซื้อขายจริงที่ไหนเลย** (ทั้งแอปและ Worker) และไม่มีที่ให้ใส่ API key ของโบรกเกอร์ — ทุกคำสั่งเติมพอร์ตจำลองที่ราคาตลาดจริง

| ส่วน | ไฟล์ |
|---|---|
| ตัวประเมินกฎ + พอร์ตจำลอง (ไม่มี network/DOM — ใช้ร่วมกันทั้งแอปและ Worker) | `autobot.js` · เทสต์ `scripts/test_autobot.cjs` (36 ข้อ) |
| หน้า พอร์ตลงทุน → **บอทเทรด** | `index.html` (`renderAutoBot` · ฟอร์มกฎ · เชื่อม Worker) |
| Cloudflare Worker: cron ทุก 15 นาที · KV · Bearer token · CORS | `cloudflare-worker/autobot/` (worker.js · wrangler.toml · README.md) · เทสต์ `scripts/test_autobot_worker.mjs` (19 ข้อ, KV/fetch จำลอง) |

กฎ: โบรกเกอร์ · สินทรัพย์ · ซื้อ/ขาย · จำนวนเงินต่อครั้ง · เงื่อนไข · พักกี่วันหลังทำ · วงเงินรวมของกฎ · เปิด/ปิด
เงื่อนไข: ตามรอบ DCA (ทุกสัปดาห์วัน… / ทุกเดือนวันที่ 1–28 · เวลาไทย · ทำครั้งเดียวต่อรอบ ตามหลังได้ถ้าพลาดวัน) ·
ราคา ≤ / ≥ · ลดลงจากจุดสูงสุด 52 สัปดาห์ ≥ X% · RSI ≤ / ≥

กันพลาด: ไม่ซื้อเกินเงินสดจำลอง (นับคำสั่งก่อนหน้าในรอบเดียวกัน) · ขายได้ไม่เกินที่ถือ · ระยะพัก · วงเงินรวม ·
ค่าธรรมเนียมโดยประมาณ (Binance 0.1% · หุ้นไทย 0.157% · Dime/Streaming 0) · ทุกรอบบันทึกเหตุผลที่ "ไม่ทำ" ของแต่ละกฎ (ไทย/อังกฤษ)

ข้อมูลราคา: แอปใช้ `finOS_actions` (market-data.json ดิบ — `loadMarketData()` เก็บแค่ macro จึงใช้ไม่ได้ เจอระหว่างทดสอบ) ·
USD/THB ใช้ค่าที่ merge แล้ว · Worker ใช้ market-data.json จาก GitHub Pages + ราคา crypto สดจาก `data-api.binance.vision`

สองโหมด: ยังไม่เชื่อม Worker = เก็บในเครื่อง ตรวจเมื่อกดปุ่ม · เชื่อมแล้ว = กฎ/พอร์ตอยู่ใน KV ตรวจเองทุก 15 นาที (แอปเก็บสำเนากฎไว้ในเครื่องด้วย)
token ของ Worker เข้ารหัสด้วย vault ถ้าตั้งรหัสผ่านไว้

## ตรวจแล้ว
- เทสต์ JS 14 ชุดผ่าน (ใหม่: `test_autobot.cjs` · `test_autobot_worker.mjs`)
- เบราว์เซอร์จริง: เพิ่มกฎผ่านฟอร์ม → ตรวจ → DCA BTC ซื้อ ฿1,000 ที่ราคา pipeline จริง · กฎขายตาม RSI ทำงาน · รอบถัดไปข้ามด้วยเหตุผลถูกต้อง · กฎไม่มีชื่อถูกปฏิเสธ
- ภาพหน้าจอ light/dark/มือถือ/อังกฤษ · ไม่มี JS error ไม่ล้นจอ
- **ยังไม่ได้ deploy Worker จริง** (ต้องใช้บัญชี Cloudflare ของคุณ — ขั้นตอนใน README)

## เฟส 2 (เงินจริง) — ยังไม่ทำ ต้องตัดสินใจหลังดูผล paper
- Binance: key แบบ trade-only ปิด withdraw + จำกัด IP · เก็บเป็น Worker secret
- หุ้นไทย: Settrade Open API ผ่านโบรกเกอร์ที่รองรับ (ขอ App ID/Secret)
- Dime/Streaming: ไม่มี API → แจ้งเตือนให้ไปกดเอง (ต่อกับ Web Push เดิม)
- วงเงินต่อวัน/ต่อคำสั่งที่ Worker บังคับเอง · ปุ่มหยุดฉุกเฉิน · log ทุกคำสั่ง
