# v88 — ปุ่ม "เพิ่ม" อยู่ที่ปุ่ม + ที่เดียว · ตรวจเมนูข้าง/แถบบนว่าซ้ำไหม

คำขอ (2026-11-11): เมนูในหน้าต่าง ๆ ซ้ำกับปุ่ม + (เช่น "+ เพิ่มหนี้" ในหน้าหนี้สิน) → ตรวจทุกหน้า **ซ้ำให้ตัดออก · ยังไม่มีให้เพิ่มในปุ่ม +** ·
เมนูข้าง (side bar) และแถบบน (top bar) ให้ **ตรวจก่อนว่าซ้ำไหม** แล้วค่อยแก้ในขั้นถัดไป

## ปุ่มเพิ่มในหน้า → ปุ่ม +
| หน้า | ปุ่มเดิม | ตอนนี้ |
|---|---|---|
| พอร์ต › ภาพรวมพอร์ต (Holdings) | + เพิ่มรายการลงทุน | ตัดออก (ปุ่ม + → ซื้อ / ขาย / ปันผล) |
| หนี้สิน › ภาพรวมหนี้ / ตารางผ่อน | + เพิ่มหนี้ · + เพิ่มหนี้ก้อนแรก | ตัดออก (ปุ่ม + → หนี้ / สัญญาผ่อน) |
| เอกสาร | ＋ เพิ่มเอกสาร · ＋ เพิ่มทีละรายการ | ตัดออก (ปุ่ม + → เอกสาร) |
| เอกสาร | ⇪ นำเข้าจาก Drive | **ย้ายเข้าปุ่ม +** (นำเข้าเอกสารจาก Drive) |
| ประกัน | ＋ เพิ่มกรมธรรม์ (บนรายการ · หน้าว่าง) | ตัดออก (ปุ่ม + → กรมธรรม์ประกัน) |
| ประกัน (แถวกรมธรรม์) | ＋ เพิ่มความคุ้มครอง | **ย้ายเข้าปุ่ม +** (ความคุ้มครองประกัน — ปิดไว้จนกว่าจะมีกรมธรรม์) · ในแถวเหลือ ✎ แก้ไขกรมธรรม์ / ความคุ้มครอง |
| บัญชี (ตารางเทียบยอด) | 🏦 จดยอดจริง | ตัดออก (ปุ่ม + → ยอดจริงจากธนาคาร) |
| เป้าหมาย | + Add goal · การ์ด "Add new goal" | **ย้ายเข้าปุ่ม +** (เป้าหมายการเงิน → เปิดหน้าเป้าหมายพร้อมฟอร์ม) |
| พอร์ต › บอทเทรด | + เพิ่มกฎ | **ย้ายเข้าปุ่ม +** (กฎบอทเทรด → เปิดหน้าบอทพร้อมฟอร์ม) |

- หน้าที่ยังไม่มีข้อมูลบอกทางแทนปุ่ม: "กดปุ่ม ＋ มุมขวาล่าง → …" (`fabHint`)
- **ที่ยังอยู่ในหน้า (ไม่ใช่การเพิ่มรายการใหม่ จึงไม่ซ้ำ)**: ✎ แก้ไข (หนี้ · เป้าหมาย · กฎบอท · กรมธรรม์) · บันทึกจ่ายรายหนี้ (เติมข้อมูลหนี้ก้อนนั้นให้) ·
  แตะแถวรายการเพื่อแก้ · ตั้งค่า (Worker · กระเป๋า MetaMask · งบรายหมวด · ปรับสมดุล) · ปุ่มเพิ่มที่อยู่ "ในฟอร์ม" (เพิ่มความคุ้มครองในฟอร์มกรมธรรม์ · เพิ่มในรายการราคาในฟอร์มลงทุน)

## ปุ่ม + (13 ปุ่ม)
- **เงิน**: รายรับ-รายจ่าย · จ่ายบัตรเครดิต · โอนระหว่างบัญชี · ยอดจริงจากธนาคาร
- **ลงทุน**: ซื้อ / ขาย / ปันผล · หุ้น / กองทุนตัวใหม่ · กฎบอทเทรด
- **อื่น ๆ**: เป้าหมายการเงิน · หนี้ / สัญญาผ่อน · กรมธรรม์ประกัน · ความคุ้มครองประกัน · เอกสาร · นำเข้าเอกสารจาก Drive
- สองคอลัมน์ทุกขนาดจอ (จอโน้ตบุ๊กคอลัมน์เดียวสูงเกิน) · มือถือแนวนอนสามคอลัมน์ · ปุ่มที่ใช้ไม่ได้บอกเหตุผล (tooltip)

## ตรวจเมนูข้าง + แถบบน (ยังไม่แก้ — รอผู้ใช้ตัดสินใจ)
**เดสก์ท็อป (> 768px)** — เมนูข้าง: ภาพรวม · บทวิเคราะห์ · เป้าหมาย · เงินเข้า-ออก · บัญชี · หนี้สิน · ประกัน · พอร์ตลงทุน · ตลาด & จังหวะ · เอกสาร (+ หมวดย่อย) · การแจ้งเตือน ·
แถบบน: ค้นหา (⌘K) · Sync · ธีม · ⚙ (ภาษา · ตั้งค่าการแจ้งเตือน · PDF · Backup · Restore) · 🔔 · รูปบัญชี (บัญชีและความปลอดภัย · ล็อก · ออกจากระบบ)
1. **ซ้ำ**: "การแจ้งเตือน" ในเมนูข้าง กับ 🔔 แถบบน — ไปหน้าเดียวกัน

**มือถือ (≤ 768px)** — แถบล่าง: ภาพรวม · เงิน · พอร์ต · ตลาด · อื่น ๆ (เปิดเมนูข้าง) · 🔔 ลอยมุมขวาบน · ท้ายเมนูข้าง: Sync · TH/EN · ธีม · บัญชีผู้ใช้ · แจ้งเตือน · ล็อก · PDF · Backup · Restore
2. **ซ้ำ**: ภาพรวม · เงิน · พอร์ต · ตลาด อยู่ทั้งแถบล่างและในเมนูข้าง (เมนูข้างแสดงครบ 11 กลุ่ม)
3. **ซ้ำ**: 🔔 ลอย กับ "การแจ้งเตือน" ในเมนูข้าง
4. **ชื่อชนกัน (ไม่ซ้ำแต่สับสน)**: ปุ่ม "แจ้งเตือน" ท้ายเมนูข้าง = *ตั้งค่า*การแจ้งเตือน ไม่ใช่หน้าการแจ้งเตือน

ไม่ซ้ำ (ตั้งใจ): ปุ่มตั้งค่าท้ายเมนูข้างบนมือถือ = ⚙ + เมนูบัญชีบนเดสก์ท็อป (แสดงคนละขนาดจอ) · ⌘K ค้นหาทุกหน้า (เป็นตัวค้นหา ไม่ใช่เมนู) · หมวดเอกสารในเมนูข้าง (เดสก์ท็อป) กับแท็บหมวดในหน้า (มือถือเท่านั้น)
