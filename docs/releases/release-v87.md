## 1. ยอดจริงจากแอปธนาคาร (แท็บ Reconcile)
- ปุ่ม + → 🏦 ยอดจริงจากธนาคาร · หน้าบัญชี → ตาราง "เทียบยอด" มีปุ่ม "จดยอดจริง" (เดิมบอกให้ไปสร้างแท็บเอง)
- กรอกได้ **หลายบัญชีในครั้งเดียว** (ไม่ต้องครบ) · แต่ละแถวบอก "ในแอป" = ยอดในชีต ณ สิ้นวันที่เลือก และ "จดล่าสุด"
- พิมพ์แล้วเห็นผลต่างทันที: ✓ ตรง (±1 บาท) หรือ ±฿x
- **บัตรเครดิต/สินเชื่อ กรอก "ยอดค้าง" เป็นบวก** แบบที่แอปธนาคารแสดง → เก็บติดลบ (ชีตเก็บหนี้เป็นค่าลบ) · กรอกติดลบ = จ่ายเกิน → เก็บบวก
- เขียนต่อท้ายแท็บ Reconcile ตามลำดับหัวคอลัมน์จริง · ไม่มีแท็บ → สร้างพร้อมหัว `Date · Account · Actual_Balance · Note`
- `reconPlanRows` · `reconRowValues` (shared.js)

## 2. หุ้น/กองทุนตัวใหม่ (แท็บ Asset_Live_Price_Feed)
- ปุ่ม + → 🏷 หุ้น / กองทุนตัวใหม่ — เพิ่มตัวใหม่ หรือเลือกตัวเดิมเพื่อแก้ (เช่น ตั้ง Inactive · แก้ชื่อ/อุตสาหกรรม)
- **ฟอร์มลงทุน**: พิมพ์ ticker ที่ยังไม่อยู่ในรายการราคา → เตือน "ชื่อ อุตสาหกรรม และราคาจะว่าง" + ปุ่ม "เพิ่มในรายการราคา"
  (ฟอร์มซ้อนบนฟอร์มลงทุน · บันทึกแล้วกลับมากรอกการซื้อต่อ) · ตัวที่ Inactive นับว่ามีแล้ว
- ticker ซ้ำ → ไม่บันทึก บอกให้เลือกตัวเดิมเพื่อแก้

## 3. ประกัน (Insurance_Policies · Insurance_Coverage)
- ปุ่ม + → 🛡 ประกัน · หน้าประกัน: "＋ เพิ่มกรมธรรม์" · แตะกรมธรรม์ → "✎ แก้ไขกรมธรรม์" / "＋ เพิ่มความคุ้มครอง" · แตะรายการความคุ้มครองเพื่อแก้/ลบ
- ฟอร์มกรมธรรม์ (แก้) แสดงความคุ้มครองของเล่มนั้น เพิ่ม/แก้ต่อได้ · ลบได้ (ยืนยันก่อน · กู้ได้จาก Version history)
- ยังไม่มีแท็บ → สร้างพร้อมหัวตารางแบบที่แอปอ่าน (หัวอยู่แถว 2)
- หน้าประกันที่ยังไม่มีข้อมูล: ปุ่ม "เพิ่มกรมธรรม์" (เดิมบอกให้เพิ่มแท็บใน Excel แล้ว upload)

## ฟอร์มแถวชีตทั่วไป (ใช้กับข้อ 2–3)
- อ่าน **หัวตารางจริง** ของแท็บทุกครั้งที่เปิด — ชีตผู้ใช้มีคอลัมน์เพิ่ม/สลับได้ · ช่องตามชนิด (วันที่ · ตัวเลข · ข้อความ + รายการค่าที่เคยใช้)
- **คอลัมน์สูตรไม่ให้กรอกและไม่เขียนทับ** (atFormulaKinds แบบ v83): สูตรรายแถวคัดลอกลงแถวใหม่ (ถ้าแถวล่าสุดถูกพิมพ์ทับ คัดลอกจากแถวแรก) ·
  ARRAYFORMULA ไม่แตะ · แก้แถวเดิม: อ่านสูตรของแถวนั้นก่อน ช่องที่เป็นสูตรไม่เขียน · ฟอร์มบอกว่าคอลัมน์ไหนชีตคำนวณเอง
- อ่านแท็บสดอีกรอบก่อนเขียน: แถวที่แก้เปลี่ยนไปแล้ว → ยกเลิก (กันเขียนทับรายการอื่น)
- ค่าที่เขียน: ตัวเลขรับจุลภาค/฿ · วันที่ ISO หรือ วัน/เดือน/ปี · ข้อความขึ้นต้น `= + @` หรือเลข 0 นำหน้า (เลขกรมธรรม์) ใส่ `'` ไม่ให้กลายเป็นสูตร/ตัด 0
- ค่าเริ่มต้น: สถานะ = ค่าที่ใช้บ่อยในแท็บ · หน่วยความคุ้มครอง = Lump Sum (ไม่เดาจากแถวอื่น)
- `srfColumns` · `srfWriteValue` · `srfFindRow` · `srfLastDataRow` (shared.js) · `SRF_SPECS` · `srfOpen/srfSave/srfDelete` (index.html)

## 4. แถบเมนูด้านบนบนมือถือ
- เดิม (v66) แท็บห่อเป็นชิปหลายแถว — กลุ่มพอร์ตมี 7 แท็บ = 3 แถว ติดขอบบนกินที่ ~150px ดูลอย · แถวบนสุดชิดแถบสถานะ iPhone
- ภาพผู้ใช้: แถวบนสุดและปุ่มกระดิ่งเบลอ แถวล่างคม — CSS ของแอปไม่มี blur เลย → น่าจะเป็นเอฟเฟกต์ขอบบนของ iOS ที่ทับเนื้อหาใต้แถบสถานะ
  (ทดสอบบน iPhone จริงไม่ได้ · Chrome จำลองไม่ได้)
- ตอนนี้: **แถวเดียวเลื่อนแนวนอน** (แท็บที่เลือกเลื่อนมากลางเสมอ · แท็บที่โผล่ครึ่งตัวบอกว่าเลื่อนได้) · แถบทึบ เว้นจากแถบสถานะมากขึ้น ·
  ที่ว่างของกระดิ่งเป็นขอบขวาสีพื้น (แท็บไม่ไหลลอดใต้กระดิ่ง) · กระดิ่ง 34px อยู่กึ่งกลางแถวเดียวกัน
