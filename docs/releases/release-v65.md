# v65 — ธีม Slate + สลับภาษาไทย / English

ฐาน: v64 · แบบอ้างอิง: ไฟล์ตัวอย่าง Dark theme (Slate) ที่ผู้ใช้ส่งมา

## ธีม
- **Slate (ค่าเริ่มต้นใหม่)** ตามแบบ: พื้น `#0F172A` · การ์ด `#1E293B` + เงา · เส้น `#334155` ·
  ตัวหนังสือ `#F8FAFC` / `#94A3B8` · สถานะ เขียว `#10B981` แดง `#EF4444` ฟ้า `#3B82F6` ·
  ฟอนต์ **Inter + Noto Sans Thai** (ตัวหนังสือหลักเป็น sans) · ผ่าน WCAG AA (muted บนการ์ด 5.7:1)
- **Midnight** = ธีมเดิมก่อน v65 ทุกค่า (สี · ฟอนต์ mono · เส้น scanline)
- ปุ่ม **◐ Slate / Midnight** ท้ายเมนูข้าง (มือถือ: เมนู "อื่น ๆ") · จำค่าไว้ในเครื่อง ·
  ตั้งธีมก่อน paint แรก (ไม่กะพริบ) · `theme-color` ของแถบสถานะมือถือเปลี่ยนตาม
- **สีในกราฟอ่านจากธีม** — เดิม hardcode สี Midnight 28 จุดใน Chart.js → ตัวแปร `--c-*` ผ่าน `CT`
  สลับธีมแล้วกราฟวาดใหม่ทันที

## ภาษา TH / EN (ขอบเขต: โครงหน้า + ป้ายหลัก)
- ปุ่ม **TH | EN** ท้ายเมนูข้าง · จำค่าไว้ · สลับได้ทันทีไม่ต้องโหลดหน้าใหม่ · สลับกลับได้ภาษาไทยเดิมทุกตัวอักษร
- แปล: เมนู/แถบล่าง · แท็บ · หัวข้อ+คำอธิบายหน้า · หัวการ์ด · หัวตาราง · ปุ่ม · ฟอร์ม/placeholder/tooltip ·
  สถานะ (ผ่าน/ไม่ผ่าน/เกินแล้ว!…) · ป้ายที่มีตัวเลข (≈90 กฎ เช่น "ใช้ไป ฿X" → "Spent ฿X") · ชื่อชุดข้อมูลในกราฟ ·
  รูปแบบวันที่ (`LOC` = en-US)
- **คงภาษาไทย:** ข้อความวิเคราะห์ยาว ๆ (Analyst Desk · คำอธิบายกติกาหน้าสัญญาณ/บอท · รายละเอียดใน "ต้องลงมือ") และ
  ข้อมูลของผู้ใช้เอง (รายละเอียดรายการ ชื่อหมวดจากชีต)
- กลไก: `i18n.js` (ไฟล์ใหม่) แปลที่ DOM ด้วยพจนานุกรม + regex, MutationObserver จับหน้าที่ render ใหม่,
  เก็บต้นฉบับใน WeakMap · ข้อความที่ถูกแยกหลายท่อนด้วยแท็กใช้ `_L(ไทย, อังกฤษ)` ใน template
- เพิ่มคำแปล: ใส่ `'ไทย':'English'` ใน `DICT` ของ `i18n.js`

## บั๊กที่เจอระหว่างทดสอบ
- เปิดแอปแล้วกดเปลี่ยนหน้าระหว่างกำลังกู้ข้อมูลจาก cache → ถูกดีดกลับ Overview (`gsInit` สั่ง `switchPage('overview')` ตายตัว)
  → อยู่หน้าที่เปิดไว้ แบบเดียวกับที่ v54 ทำฝั่ง sync
