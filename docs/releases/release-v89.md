# v89 — เมนูข้าง / แถบบน / แถบล่าง ไม่ซ้ำกัน

คำขอ (2026-11-11): ทำทั้ง 3 ข้อจากผลตรวจใน v88

## 1. "การแจ้งเตือน" ซ้ำกับ 🔔 → ถอดออกจากเมนูข้าง
- ลบ "ระบบ › การแจ้งเตือน" (และ badge ในเมนูข้าง) · หน้าการแจ้งเตือนเปิดจาก 🔔 (แถบบนเดสก์ท็อป · ปุ่มลอยมุมขวาบนมือถือ) และ ⌘K
- badge จำนวนที่ยังไม่อ่านยังขึ้นที่ 🔔 ทั้งสองที่ (`_ntBadge`)

## 2. มือถือ: เมนู "อื่น ๆ" ไม่ซ้ำกับแถบล่าง
- แถบล่างมี ภาพรวม · เงิน · พอร์ต · ตลาด อยู่แล้ว → เมนู "อื่น ๆ" แสดงเฉพาะ **บทวิเคราะห์ · เป้าหมาย · บัญชี · หนี้สิน · ประกัน · เอกสาร** + ปุ่มตั้งค่า
  (class `sb-dup-bnav` · ซ่อนเฉพาะ ≤ 768px ซึ่งเป็นช่วงเดียวกับที่แถบล่างแสดง · หัวข้อ "ลงทุน" ที่ว่างแล้วซ่อนด้วย)
- เดสก์ท็อปเมนูข้างยังแสดงครบทุกกลุ่ม (ไม่มีแถบล่าง)
- ปุ่ม "อื่น ๆ" ไฮไลต์เมื่ออยู่ในหน้าที่มาจากเมนูนี้ (เช่น บัญชี · หนี้สิน) — เดิมไม่มีปุ่มไหนไฮไลต์เลย ไม่รู้ว่าอยู่ตรงไหน

## 3. ปุ่ม "แจ้งเตือน" ท้ายเมนูข้าง → "ตั้งค่าแจ้งเตือน"
- ปุ่มนี้คือ *ตั้งค่า*การแจ้งเตือน (`ntOpenSetup`) แต่ชื่อเดิมชนกับหน้าการแจ้งเตือน · ชื่อยาวขึ้นจึงแยกเป็นแถวของตัวเอง (อังกฤษ "Notification settings" ไม่ล้นปุ่ม)

## เจอระหว่างทดสอบ (แก้แล้ว)
- มือถือ: แถบชวนตั้งรหัสผ่าน (ลอยเหนือแถบล่าง) ทับปุ่มท้ายเมนู "อื่น ๆ" — กด "ตั้งค่าแจ้งเตือน" · PDF · Backup ไม่ได้ขณะแถบนี้แสดง → ซ่อนแถบนี้ระหว่างเปิดเมนู

## ตรวจแล้ว
- เดสก์ท็อป 1366: เมนูข้าง 10 กลุ่ม (ไม่มีการแจ้งเตือน) · 🔔 แถบบนมี badge และเปิดหน้าการแจ้งเตือน · ⌘K ยังหา "การแจ้งเตือน" และ "ตั้งค่าการแจ้งเตือน" เจอ และเปิดหน้าได้
