# v76 — ตัดเมนูตั้งค่าที่ซ้ำกัน

คำขอ: "พบเจอเมนูซ้ำซ้อนเยอะมาก" — (1) เมนูตั้งค่ามีธีม แต่มีปุ่มธีมอยู่แล้ว (2) ตั้งค่า Google Sheets มีทั้งเมนูตัวเองและอยู่ในบัญชีและความปลอดภัย → เหลือแค่ในบัญชีฯ
(3) ย้ายตั้งค่าการแจ้งเตือนมารวมกับเมนูตั้งค่า ให้หน้าการแจ้งเตือนเป็นการแจ้งเตือนอย่างเดียว (4) ยุบ "รหัสผ่านและล็อกอัตโนมัติ" เพราะคือหน้าต่างเดียวกับบัญชีและความปลอดภัย

## เปลี่ยนอะไร

| ที่ | ก่อน | หลัง |
|---|---|---|
| เมนู ⚙ (แถบบน) | ธีม · ภาษา / ตั้งค่า Google Sheets · ตั้งค่าการแจ้งเตือน · รหัสผ่านและล็อกอัตโนมัติ / PDF · Backup · Restore | ภาษา / **ตั้งค่าการแจ้งเตือน** / PDF · Backup · Restore |
| ธีม | ปุ่มบนแถบบน + แถวในเมนู ⚙ | ปุ่มบนแถบบนอย่างเดียว (กดวน Light → Dark → Auto) |
| Google Sheets (Client ID / Spreadsheet ID) | เมนู ⚙ + ปุ่ม "ตั้งค่า Sheets" ในบัญชีฯ + ⌘K + ปุ่มเฟืองในเมนูมือถือ | รูปโปรไฟล์ → บัญชีและความปลอดภัย → ตั้งค่า Sheets (⌘K "sheets" พาไปหน้าต่างบัญชีฯ) · หน้าเข้าสู่ระบบยังมีลิงก์ของตัวเอง (ยังเข้าแอปไม่ได้) |
| รหัสผ่าน / ล็อก | "รหัสผ่านและล็อกอัตโนมัติ" ในเมนู ⚙ เปิดหน้าต่างเดียวกับบัญชีฯ | รูปโปรไฟล์ → บัญชีและความปลอดภัย |
| ตั้งค่าการแจ้งเตือน (กุญแจ · เปิด push · ทดสอบ) | ปุ่ม ⚙ ในหน้าการแจ้งเตือน (กางในหน้า) | **หน้าต่าง** "ตั้งค่าการแจ้งเตือน" เปิดจากเมนู ⚙ · ⌘K · ปุ่ม "แจ้งเตือน" ในเมนูมือถือ |
| หน้าการแจ้งเตือน | รายการ + ปุ่ม ⚙ ตั้งค่า | รายการอย่างเดียว · คำเตือนกุญแจ / ยังไม่มีกุญแจ / "ลงทะเบียนเปลี่ยน" มีปุ่มลัดไปหน้าต่างตั้งค่า |

## โค้ด
- `ntOpenSetup()` / `ntCloseSetup()` เปิด-ปิด `#nt-set-modal` · `_ntSetup()` render ลง `#nt-setup` ในหน้าต่าง (เดิมอยู่ในหน้า)
  — `ntGenKeys`/`ntSubscribe`/`ntSaveKey` ยังเรียก `renderNotify()` ตามเดิม ซึ่ง render หน้าต่างซ้ำเมื่อ `_nt.setup` เปิดอยู่
- แจ้งเตือน "การลงทะเบียนเปลี่ยน" (`page:'notify'`) → ปุ่มเปิดหน้าต่างตั้งค่าแทน "ไปที่หน้าที่เกี่ยวข้อง" (ซึ่งคือหน้าที่อยู่แล้ว)
- ข้อความที่บอกให้ "เปิด ⚙ ตั้งค่า" / "⚙ ขั้น 2" ชี้ไป ⚙ ตั้งค่า → ตั้งค่าการแจ้งเตือน
- ปุ่ม + (`.tx-fab`, z-index 900) เคยลอยทับทุกหน้าต่าง (z-index 200) → ซ่อนระหว่างเปิดหน้าต่าง (`body:has(.gs-modal-overlay.show)`)
- `i18n.js`: `'แจ้งเตือน':'Notifications'` · `APP_BUILD`/`EXPECTED_SHARED_BUILD`/`CACHE_NAME` → v76

- เบราว์เซอร์ + ชีตจำลอง 1440px และ 375px: เมนู ⚙ ตามตารางบน · หน้าต่างตั้งค่าแจ้งเตือนเปิด/ปิดได้ · สร้างกุญแจแล้วหน้าต่าง render ซ้ำ (เห็น NOTIFY_KEY / VAPID_PRIVATE_KEY) ·

## รอบ 2 — แถบแท็บบนมือถือ (แนวตั้ง/แนวนอน)

คำขอ: "มือถือแนวตั้งภาพล้นเกินจอ ไม่เห็นทุกเมนู · แนวนอนเวลาเลื่อนเมนู เมนูหลุดออกจากตำแหน่ง"

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| แนวตั้ง: แถวแรกของชิปแท็บ (เช่น ภาพรวมพอร์ต · ผลตอบแทนจริง · บอทเทรด) จมอยู่ใต้แถบสถานะ iPhone · แถวสองโดนเบลอ | v74 ใส่ `.grp-tabs{padding:0 32px}` นอก media query หลังกฎมือถือของ v66 → `padding-top: 8px + safe-area` หายไป แถบ sticky ติดที่ `top:0` ซึ่งอยู่ใต้แถบสถานะ (`black-translucent`) | มือถือ: แถบติดที่ `top: safe-area` + `margin-top: safe-area` (ตำแหน่งตอนยังไม่เลื่อนตรงกัน) · padding 8px · พื้นทึบใต้แถบสถานะ `#app::before` (สูง = safe-area, จอที่ไม่มีรอยบาก = 0) ให้เนื้อหาเลื่อนผ่านใต้นาฬิกา/แบตไม่ได้ · แท็บของหน้าเอกสาร (`#docs-tabs`) ได้ผลเดียวกัน |
| แนวนอน (จอ > 768px = แบบเดสก์ท็อป): ปัดแถบแท็บแล้วแท็บหลุดลงไปครึ่งตัวใต้เส้นขอบ | แท็บมี `margin-bottom:-1px` → เนื้อหาสูงกว่ากล่อง 1px (`scrollHeight 50 > clientHeight 49`) และ `overflow-x:auto` ทำให้ `overflow-y` เป็น auto ด้วย → iOS ให้แถบเลื่อน/เด้งแนวตั้งได้ | `.grp-tabs{overflow-y:hidden;overscroll-behavior-x:contain}` — เลื่อนได้แนวนอนอย่างเดียว (มือถือแนวตั้งยังเป็น `overflow:visible` แบบชิปห่อบรรทัดเหมือนเดิม) |

ตรวจแล้ว: 430×932 + แถบสถานะจำลอง 59px (Chrome จำลอง safe-area ไม่ได้ → แทน `env()` ด้วย 59px): แถบติดใต้แถบสถานะทั้งตอนบนสุดและตอนเลื่อน เห็นครบ 3 แถว กระดิ่งตรงกับแถวแรก ·
หน้าเอกสาร · 375×812 ไม่ล้นจอ (พอร์ต 3 แถว 114px · ตลาด/เงิน 2 แถว 80px) · 932×430 `overflow-y: hidden` · 1440 แถบเดสก์ท็อปเหมือนเดิม · ไม่มี JS error
