## ต้นเหตุ
`line_notify.py` อ่านแท็บ Asset_Tracker และ Asset_Live_Price_Feed แบบ **ค่าที่จัดรูปแบบแล้ว** (ตามที่เซลล์แสดง)
ขณะที่แอปอ่าน **ค่าดิบ** (`UNFORMATTED_VALUE`) — จำนวนหน่วยทศนิยมเล็กถูกปัดตามรูปแบบเซลล์
(DCA 0.0000234 BTC → "0.00" = 0) จึงหายเกือบทั้งกลุ่มที่ซื้อทีละน้อย (คริปโต · เศษหุ้น US) ·
กองทุนที่ซื้อเป็นหน่วยเต็มรอด จึงตรงกัน

## แก้ (`scripts/line_notify.py`)
- อ่าน Asset_Tracker + แท็บราคาแบบค่าดิบ เหมือน Sync ของแอป (วันที่เป็น serial อ่านได้อยู่แล้ว)
- `_f()` รับค่าที่มี ฿ / $ / คอมมา / วงเล็บติดลบ (เดิม "฿1,234" → 0 เงียบ ๆ)
- จับกลุ่มเหมือน `resolveGroup()` ในแอป (ไม่สนตัวพิมพ์/ช่องว่าง/ขีด + ชื่อเรียกอื่น + ticker ทอง)
- ต้นทุน = running WACC เหมือน `runningCostBasis()` (v68) → "กำไรที่ยังไม่ขาย" ตรงกับแอป
- ฐาน "รอบก่อน/สัปดาห์/เดือน" ที่คิดด้วยสูตรเก่า ไม่เอามาเทียบมูลค่า (กัน "+฿200,000 (+100%)" ปลอมรอบแรก) · ราคาต่อหน่วยยังเทียบได้
