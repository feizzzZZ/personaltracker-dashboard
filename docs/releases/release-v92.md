# v92 — ปรับ workflow: เทสต์อัตโนมัติ · เตือนรายการซ้ำ · ต่ออายุ session ระหว่างกรอก · sync เร็วขึ้น · สำรองชีต

คำขอ (2026-11-22): "workflow การทำงาน มีตรงไหนที่ improve ให้ดีกว่านี้ได้อีกไหม" → เสนอ 8 ข้อ → ผู้ใช้: "จัดทุกอันมาได้เลย"

## ในแอป
1. **เตือนรายการที่น่าจะซ้ำ** — ตั้งแต่ v86 ทุกรายการเข้าทางแอป เผลอบันทึกซ้ำก็ลงชีตไปเลย
   - รายรับ-รายจ่าย / โอน / จ่ายบัตร: วันเดียวกัน · ประเภทเดียวกัน · บัญชีเดียวกัน · ยอดเท่ากัน → "⚠ มีรายการนี้ในชีตแล้ว (แถว n · หมวด · รายละเอียด · ยอด) — ถ้าเป็นอีกรายการจริง กดบันทึกอีกครั้ง"
   - ซื้อ/ขาย/ปันผล: วัน · ticker · ประเภท · จำนวน · ราคาเดียวกัน
   - เป็นคำเตือน ไม่ห้าม (ซื้อของราคาเท่ากันสองครั้งในวันเดียวเกิดได้จริง) · แก้ค่าในฟอร์ม = ตรวจใหม่ · แก้รายการเดิมไม่ตรวจ
   - `findDuplicateTx` / `findDuplicateAt` ใน `shared.js` · เทสต์ `tests/test_entry_checks.cjs`
2. **Session Google หมดอายุระหว่างกรอก — ข้อมูลไม่หายแล้ว** (ค้างจาก v91)
   - ก่อนเขียนชีตทุกฟอร์ม (`gsWriteAuth`): token หมดหรือเหลือ < 3 นาที → ต่ออายุเงียบก่อนแล้วบันทึกต่อเลย
   - ต่ออายุเงียบไม่ได้ → แถบ "🔑 Session Google หมดอายุ · [เข้าสู่ระบบ Google]" ลอยเหนือฟอร์ม · ฟอร์มยังเปิดพร้อมค่าที่กรอก · เข้าระบบแล้วแถบบอก "กดบันทึกอีกครั้งได้เลย"
   - กลับเข้าแอปก่อนครบรอบ sync 15 นาทีแต่ token หมด (มือถือหยุด timer ตอนแอปอยู่เบื้องหลัง) → ต่ออายุไว้ก่อน
   - 401 ระหว่างเขียน = "หมดอายุระหว่างบันทึก — กดบันทึกอีกครั้ง" (เดิมขึ้น "ไม่มีสิทธิ์เขียน" ซึ่งผิด) · 403 ยังเป็นไม่มีสิทธิ์
   - ครอบคลุม: รายการเงิน · ลงทุน · รายการราคา/ประกัน (รวมลบ — เดิมไม่ตรวจเลย) · ยอดจริง · หนี้ · เอกสาร · นำเข้าจาก Drive
3. **ยอดจริงเก่ากว่า 45 วันไม่เงียบแล้ว** (ค้างจาก v91) — แอปกลับไปใช้ยอดคำนวณโดยไม่บอก
   - การ์ดบัญชี: "⏳ ยอดจริง 2026-09-01 · เก่า 82 วัน" · หน้าภาพรวม "ต้องลงมือ": รายชื่อบัญชี + จำนวนวัน · ฟอร์มยอดจริง: "จดล่าสุด … · เก่า n วัน" สีส้ม
   - `reconStaleList` ใน `shared.js` (ใช้เกณฑ์ `RECON_TRUST_DAYS` เดียวกับ `applyReconciliation`)
4. **บันทึกแล้วรอน้อยลง**
   - sync อ่านแท็บเสริม 7 แท็บพร้อมกันกับแท็บหลัก (เดิมอ่านต่อกันทีละแท็บ 8 รอบ) · ข้อมูลตลาดดึงคู่ขนานไปด้วย
   - sync หลังบันทึกฟอร์ม (`gsSync({light:true})`) อ่านชีตอย่างเดียว ไม่ดึง market-data.json / fundamentals / bot-paper / แจ้งเตือนใหม่ (การบันทึกไม่ได้เปลี่ยนข้อมูลตลาด)

## ต้องทำเอง (ครั้งเดียว · ไม่ทำก็ได้ แอปใช้ได้ปกติ)
- **deploy Worker อัตโนมัติ**: Cloudflare → My Profile → API Tokens → Create Token → template **Edit Cloudflare Workers** → คัดลอก token →
  GitHub repo → Settings → Secrets and variables → Actions → New repository secret ชื่อ `CLOUDFLARE_API_TOKEN` (ถ้า token เข้าถึงหลายบัญชี ใส่ `CLOUDFLARE_ACCOUNT_ID` ด้วย)
  — ห้ามวาง token ในแชต · ทดสอบ: แท็บ Actions → deploy-worker → Run workflow
- **สำรองชีต**: เปิดชีต → Extensions → Apps Script → วางไฟล์ `scripts/apps_script/sheet_backup.gs` ทั้งไฟล์ → Save → เลือก `installWeeklyBackup` → Run → อนุญาต
- หลัง merge: ปิด-เปิดแอปหนึ่งครั้งให้ service worker v92 ติดตั้ง
