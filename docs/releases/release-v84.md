# v84 — ยอดบัญชีในแอปไม่ตรงกับชีต (SCB) · รายการวันเดียวกับวันจดยอด Reconcile

บั๊กที่ผู้ใช้เจอ (2026-11-02): กรอกรายรับรายจ่ายผ่านเว็บแอปแล้ว ยอด **SCB ในแอป ฿17,735** แต่ชีต Transaction แถว Current Balance = **15,734.53**
(ต่าง ≈ ฿2,000 · บัญชีอื่นตรงหมด) · การ์ดทุกใบขึ้น ✓

## สาเหตุ
- หน้า บัญชี ไม่ได้โชว์แถว Current Balance ตรงๆ เมื่อบัญชีมียอดจริงในชีต **Reconcile** (v68):
  ยอดบนการ์ด = **ยอดจริงที่จด + รายการที่ลงวันที่ *หลัง* วันจด**
- วันที่ใน Reconcile ไม่มีเวลา โค้ดจึงถือว่ายอดจริง = ยอด **สิ้นวัน** → รายการ **วันเดียวกัน** ถือว่ารวมอยู่แล้ว ไม่นับซ้ำ
- ถ้าจดยอดจากแอปธนาคาร**ตอนเช้า** แล้วกรอกรายจ่ายของวันนั้นผ่านเว็บแอปทีหลัง → ชีตลบรายการเหล่านั้นแล้ว แต่แอปไม่ลบ →
  ยอดในแอปสูงกว่าชีตเท่ากับยอดรวมรายการวันนั้น
- ทดสอบกับ main (v83) ด้วยชีตจำลองหน้าตาแบบผู้ใช้ (จดยอด SCB 1 พ.ย. ตอนเช้า 17,734.53 · รายจ่าย 1 พ.ย. รวม 2,000): การ์ด **SCB ฿17,735 ✓** ตรงกับภาพผู้ใช้ ·
  ตาราง "เทียบยอด" ฟ้อง +฿2,000 แต่การ์ดยังขึ้น ✓

## แก้
- `reconMovement(rows, name, rec, balNow, tol)` ใน shared.js — ถ้ายอดจริง**ไม่ตรง**กับยอดคำนวณสิ้นวันจด ลองตัดรายการของวันนั้นออกทีละแถว**จากท้าย**
  (ลำดับแถวในชีต = ลำดับที่กรอก · เว็บแอปเพิ่มแถวต่อท้ายเสมอ) · ตรงที่จุดไหน (±1 บาท) → แถวหลังจุดนั้นนับเป็น "กรอกหลังจดยอด"
  - ตรงกับยอดสิ้นวันอยู่แล้ว → เหมือนเดิมทุกอย่าง
  - ไม่ตรงกับจุดไหนของวันเลย → ใช้แบบสิ้นวันเหมือนเดิม — **ผลต่างจริงยังฟ้องเท่าเดิม** (ลืมกรอก / กรอกเกิน)
  - `applyReconciliation` (ยอดบนการ์ด · เงินสด · หนี้ · Net Worth · FIRE) และ `computeReconciliation` (ตารางเทียบยอด · "ต้องลงมือ") ใช้ตัวเดียวกัน
- การ์ดบัญชี: ✓ เฉพาะบัญชีที่ยอดจริงตรงกับชีต (±1 บาท) · ไม่ตรง → **"⚠ ชีต ฿x · ต่าง ±฿y"** ใต้ยอด (tooltip อธิบายว่ายอดบนการ์ดมาจากไหน)
  เดิม ✓ ขึ้นทุกบัญชีที่มีแถวใน Reconcile แม้ยอดไม่ตรง
- ตารางเทียบยอด: บรรทัด "รวมรายการวันที่ … ที่กรอกหลังจดยอด n รายการ" เมื่อมีการย้ายรายการวันเดียวกัน
