# v83 — อุตสาหกรรมจากคอลัมน์ Industry · ฟอร์มไม่เขียนทับ ARRAYFORMULA · ทดสอบบั๊ก/UX หน้าปันผล

คำขอ (2026-10-31): (1) กราฟปันผลโหมด Sectors ขึ้น **ชื่อบริษัท** แทนอุตสาหกรรม — ให้ใช้ Asset_Tracker คอลัมน์ F (Industry)
(2) หลังแก้ ให้ทดสอบบั๊กและ UX เพิ่ม

## 1. อุตสาหกรรมขึ้นเป็นชื่อบริษัท
- ป้ายในภาพของผู้ใช้ตรงกับ **คอลัมน์ E (Name)** ทุกตัว ("ธนาคารกสิกรไทย จำกัด (มหาชน)", "Apple Inc") — แปลว่าตอน sync ล่าสุด คอลัมน์ที่หัวชื่อ "Industry" มีชื่อบริษัทอยู่
- โค้ดหาคอลัมน์จากหัว "Industry" อยู่แล้ว — ทดสอบด้วยชีตหน้าตาแบบในภาพ (E = Name · F = Industry) **ทั้ง main (v82) และ v83 อ่านคอลัมน์ F ถูก** →
  ชื่อบริษัทที่เห็นมาจากข้อมูลตอน sync ครั้งก่อน (ก่อนชีตเป็นแบบปัจจุบัน) · อ่านชีตจริงตรวจไม่ได้ (Drive connector ไม่เห็นไฟล์)
- กันไม่ให้เงียบอีก:
  - หัวคอลัมน์ Asset_Tracker เทียบแบบหลวม (ตัวพิมพ์ · ช่องว่าง · ขีดล่าง) — "industry " / "Transaction Type" ก็หาเจอ
  - อุตสาหกรรมของแต่ละตัว = **แถวล่าสุด** ที่มีค่า (เดิมแถวแรก — แถวเก่าอาจกรอกแบบเดิมไว้)
  - หมายเหตุใต้กราฟทุกการ์ดในโหมด Sectors บอก **"อุตสาหกรรมจากคอลัมน์ F ("Industry")"** · ไม่พบคอลัมน์ → ⚠ · ค่า ≥ ครึ่งหนึ่งตรงกับคอลัมน์ Name → ⚠ "ตรวจหัวคอลัมน์แล้วกด Sync"
  - `window._atIndustryInfo` (คอลัมน์ · หัว · จำนวนแถว · ซ้ำกับ Name)

## 2. บั๊กที่เจอระหว่างทดสอบ (สำคัญ): ฟอร์มเพิ่ม/แก้รายการลงทุนเขียนทับ ARRAYFORMULA
ชีตผู้ใช้: F2 = `ARRAYFORMULA(IF(C2:C="", "", XLOOKUP(C2:C, Asset_Live_Price_Feed!A:A, Asset_Live_Price_Feed!D:D, …)))`
- เดิม `atFormulaCols` ดูแค่แถวอ้างอิง (แถวสุดท้าย) ซึ่งเป็น "ค่า" ที่สูตรกระจายลงมา → ไม่รู้ว่า F เป็นสูตร → ฟอร์มเขียน Industry ลง F แถวใหม่ →
  **ทั้งคอลัมน์ F กลายเป็น #REF!** (array result was not expanded) — ทดสอบกับ main แล้ว: คำขอเขียนมี `F63`
- แก้: `atFormulaKinds(row2, ref)` ใน shared.js แยก **สูตรรายแถว** (คัดลอกลงแถวใหม่เหมือนเดิม) กับ **สูตรที่กระจายทั้งคอลัมน์** (ARRAYFORMULA · FILTER · QUERY · SORT · MAP · ช่วงเปิดท้ายอย่าง `C2:C`) — ห้ามเขียน/ห้ามคัดลอก ·
  `atFormulaCols` อ่านแถว 2 + แถวอ้างอิงด้วย batchGet (FORMULA) · ผลตรวจรุ่นเก่าใน cache ไม่ใช้ (`formulaVer = 2`) · ตรวจใหม่ทุก sync
- ฟอร์ม: ช่องที่ชีตคำนวณเอง (Asset Type · Industry · Platform · FX · Commission) ถูกปิด + tooltip "ชีตคำนวณช่องนี้เองด้วยสูตร (คอลัมน์ F)"
- ผลกับชีตแบบผู้ใช้: เขียน A–D, G–K, M · ไม่แตะ E/F · คัดลอกสูตรรายแถวคอลัมน์ L
- เทสต์ `tests/test_at_formula.cjs` (11 ข้อ — รวมสูตรจริงของผู้ใช้)
