# v73 — ปรับ UX/UI ตามผลตรวจ v72 (ส่วนที่ 3)

v72 ตรวจและแก้บั๊ก logic/ความเป็นส่วนตัว แต่ตั้งใจไม่แตะ layout/flow — รอบนี้ทำส่วนนั้น
ตามลำดับผลกระทบใน `release-v72.md` ส่วนที่ 3

วิธีตรวจ (เหมือน v72)
- ชีตจำลองชุดเดิม (ธุรกรรม 942 แถว/14 เดือน · 6 บัญชีรวมบัตรเครดิตและสินเชื่อรถ · พอร์ต 13 ตัว · ประกัน 4 ฉบับ)
  ป้อนผ่าน `gsProcessData()` ตัวจริง + ข้อมูล pipeline จริงใน repo → headless Chrome ทุกหน้า 24 หน้า ที่ 1440px และ 500px
  ไม่มี JS error ไม่มีอะไรล้นจอ
- ทดสอบ flow ที่เปลี่ยน: กด "ไม่ตั้งงบ" แล้วงบรวม/ป้ายงบเกินเปลี่ยนตาม · ปุ่ม ‹ › เดือนในหน้างบ · พับ/กาง หมวด ฿0 ·
  ช่องกรอกดอกเบี้ยบนการ์ดมือถือ · สลับเป็นภาษาอังกฤษ
- เทสต์ JS ทั้ง 10 ชุดผ่าน (`test_budget.cjs` +1 ข้อ · `test_i18n.cjs` +3 ข้อ)

## ยังไม่ได้ทำ (พร้อมเหตุผล)

| เรื่อง | เหตุผล |
|---|---|
| ตารางธุรกรรม: ช่องค้นหา/กรองหมวด | เป็นฟีเจอร์ใหม่ (state ค้นหา + แบ่งหน้า + ปุ่มกรองเดิม) ไม่ใช่การจัดหน้า · ควรทำแยกพร้อมเทสต์ |
| กราฟยอดสิ้นปีของหนี้ใช้รายเดือนเมื่อข้อมูลไม่ถึง 2 ปี | ต้องเปลี่ยนแหล่งข้อมูลกราฟ (ยอดย้อนหลังรายเดือนต่อบัญชี) · ผลกระทบต่ำกว่ารายการที่ทำ |
| ตารางสัญญาณบนมือถือ: ย้ายคอลัมน์ "สรุป" มาซ้าย | ตารางสัญญาณใช้ `gateTable()` ร่วมกันสามหน้า (สัญญาณ · ภาพรวมตลาด · ของเก่า) ควรทำเป็นการ์ดมือถือแบบเดียวกับหนี้ในรอบถัดไป |
| ปุ่ม/ป้ายปนไทย-อังกฤษ (Edit · Budget · Holdings · Add goal) | ต้องเลือกนโยบายภาษาของหัวการ์ด/ปุ่มทั้งแอปก่อน (ตอนนี้หัวหน้าเป็นอังกฤษโดยตั้งใจ) · แก้ทีละจุดจะยิ่งไม่สม่ำเสมอ |
| เป้าหมายแบบจำนวนเงินผูกกับยอดบัญชี/กลุ่มสินทรัพย์ | ฟีเจอร์ใหม่ (โครงข้อมูลเป้าหมาย + UI เลือกแหล่งยอด) |

ข้อสังเกตจากข้อมูลจำลอง (ไม่ได้แก้รอบนี้):
- ค่างวดที่ลงสองคอลัมน์ (−ธนาคาร +สินเชื่อ) ยอดสุทธิ 0 จึงไม่อยู่ใน "ผ่อน/ใช้หนี้" ของ `debtSplit` (หน้ารายปีก็เช่นกัน) — ใส่ไว้ใน tooltip การ์ด DEBT แล้ว
  ถ้าอยากให้นับเป็นตัวเลขหลัก ต้องตัดสินใจนิยามใหม่ทั้งรายเดือนและรายปีพร้อมกัน
- การ์ด Expense & Bills บนหน้างบใช้สีจาก % รวม (58% เขียว) แม้มี 6 หมวดเกินงบ — ตามนิยาม v72 (เทียบเฉพาะหมวดที่ตั้งงบ) แต่อาจอยากให้มีสัญญาณว่ามีหมวดเกิน
