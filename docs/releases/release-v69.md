# v69 — พอร์ตนับ Provident Fund ทุกหน้า

ผู้ใช้: "อยากให้พอร์ตการลงทุนนับทั้งหมด เพราะเดิมเหมือนจะไม่นับ provident fund"

## ตรวจแล้ว
| จุด | ก่อน v69 |
|---|---|
| Overview · พอร์ต · Net Worth · Analyst · ปันผล · Engine · สรุป LINE/แจ้งเตือน | นับ PVD อยู่แล้ว (สรุป 9 ต.ค. ฿201,671 รวม PVD ฿142,197) |
| **หน้าปรับสมดุล** | **ตัด PVD ออกทั้งหมด** — มูลค่าก่อน/หลังและ "สัดส่วนในพอร์ต" คิดเฉพาะส่วนที่ซื้อขายได้ → ยอดไม่ตรงกับหน้าพอร์ต |

## แก้ (`rebalancePlan` ใน shared.js + หน้าปรับสมดุล)
- มูลค่าก่อน/หลังปรับ = **ทั้งพอร์ตรวม PVD** (ตรงกับหน้าพอร์ต) · การ์ดบอกว่ารวม PVD เท่าไร
- "สัดส่วนในพอร์ต" ของทุกตัวคิดบนฐานทั้งพอร์ต · PVD เป็นแถว 🔒 ขายไม่ได้ (นับในพอร์ต ไม่มีคำสั่งซื้อขาย)
- เป้ารายตัว = สัดส่วนของส่วนที่ซื้อขายได้ (PVD ขยับไม่ได้ ส่วนที่เหลือแบ่งตามเป้า) — ตั้งค่าบอกชัด + PVD แสดงเป็น 🔒
- คำสั่งซื้อขายเท่าเดิมทุกบาท (ยังไม่แนะนำให้ขาย PVD ซึ่งทำไม่ได้) · CSV มีคอลัมน์ `locked`
