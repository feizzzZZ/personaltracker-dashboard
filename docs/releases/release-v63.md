# v63 — งบประมาณนับรายจ่ายที่รูดบัตรด้วย

ฐาน: v62 (deploy แล้ว) · แก้ข้อค้างที่ 4 ใน `release-v62.md`

## อาการ
หน้า Budget นับแค่แถว `Expense`/`Bills` ส่วนรายจ่ายที่รูดบัตรบันทึกเป็นแถว `Debt` จึงไม่เข้างบเลย
งบเลยดูเหมือน "เหลือ" มากกว่าความจริง และป้ายงบเกินไม่ขึ้น

## แก้
- `shared.js` — นิยามกลางใหม่ `budgetSpendMap(rows, bals)` ใช้เกณฑ์เดียวกับ `debtSplit()`:
  แถว Debt ที่แตะบัญชีเครดิต (`isCreditAccount`) และเป็นเงินออก → นับเข้าหมวดในคอลัมน์ Type
  - แถวจ่ายบัตร (−ธนาคาร +บัตร) · คืนเงินเข้าบัตร · ค่างวด/ใช้หนี้จากบัญชีธนาคาร → **ไม่นับ**
  - แถวรูดบัตรที่พิมพ์เป็น `Expense` อยู่แล้ว (วิธีแก้ใน v62) → นับครั้งเดียวตามเดิม ไม่ซ้ำ
- `index.html` — ทุกจุดที่คำนวณงบใช้ฟังก์ชันเดียวกัน: หน้า Budget · ป้ายงบบนเมนู · Analyst "งบเกิน" ·
  Overview "งบที่เกิน" · ส่วน Budget status ใน PDF รายเดือน
  - สรุปงบบอก "รวมรูดบัตร ฿X" · การ์ดหมวดที่มียอดจากบัตรจะมี 💳 (ชี้ดูยอดได้)
- **ไม่เปลี่ยน** ยอดบัตร/ยอดหนี้/saving rate/computeSummary และ Top 5 รายจ่ายใน PDF
- `APP_BUILD` / guard → `v63` · `CACHE_NAME` → `finance-os-v63`
