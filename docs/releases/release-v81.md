## Holdings — การ์ด True cost → IRR
- ตัวใหญ่ = **IRR ทั้งพอร์ต** (ทุก flow: ซื้อรวมค่าธรรมเนียม · ขายสุทธิ · ปันผล รวมตัวที่ขายหมดแล้ว) เทียบมูลค่าพอร์ตวันนี้
- บรรทัดล่าง = **เฉพาะที่ถืออยู่** (เหมือน "current holdings" ในภาพ Snowball ที่ผู้ใช้แนบ)
- ถือ ≥ 1 ปี → XIRR ต่อปี · < 1 ปี → ผลสะสม "ใน N เดือน" ไม่แปลงเป็นต่อปี (กฎ v74 · `holdingPerf` + `perfQuote` ตัวเดียวกับ Analyst)
- มีตัวที่ไม่มีราคา → บอกว่าไม่นับมูลค่าตัวเหล่านั้น · tooltip อธิบายวิธีคิด
- `shared.js`: `irrSummary(byTk, holdings, nowT)`

## Transactions (แท็บ รายการซื้อขาย)
- ชื่อ: แท็บภาษาอังกฤษ "Trades" → **Transactions** · หัวข้อหน้า "Investment Flow" → **Transactions**
- วันที่ **YYYY-MM-DD** (`isoLocal`)
- **Dropdown ประเภท** สร้างจากค่าจริงใน `Transaction_Type` ของชีต (เรียงตามจำนวน · มีจำนวนในวงเล็บ) · sync ใหม่แล้วประเภทที่เลือกหายไป → กลับเป็น "ทุกประเภท"
- **ช่องค้นหา**: ticker · ประเภท · แพลตฟอร์ม · กลุ่ม · Asset_Type · วันที่ (พิมพ์ "2025-08" ได้ทั้งเดือน) · หลายคำ = ต้องเจอทุกคำ · ใช้ร่วมกับ dropdown ได้ ·
  เปลี่ยนเงื่อนไขแล้วกลับหน้าแรก · บรรทัดนับบอก "N จาก M รายการ"
- **คอลัมน์ Fee** = `Commission_THB` (หรือ `Commission_Fee-Tax_THB`) ของแถวนั้น · ทศนิยม 2 ตำแหน่ง · ไม่มี → "—"
- `shared.js`: `investTxTypes(rows)` · `filterInvestTx(rows, q, type)` · แถบค้นหาสร้างใน `renderAtTxTable` (สองภาษา)
