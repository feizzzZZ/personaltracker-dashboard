# v85 — ฟอร์มเพิ่มรายการ: จ่ายบัตรเครดิตได้จากฟอร์มโดยตรง

ปัญหาที่ผู้ใช้เจอ (2026-11-08): หน้า รายรับ-รายจ่าย → ➕ เพิ่มรายการ — จะเคลียร์ยอดบัตรเครดิต (เงินออกจากธนาคาร เข้าบัตร) แต่ **ไม่มีช่องให้เลือกบัตร**

## สาเหตุ
- ชีตลงจ่ายบัตรเป็นแถวเดียว: Transactions = **Debt** · หมวด "Clear Debt <บัตร>" · **ธนาคาร −x · บัตร +x** (v77)
- ช่องบัญชีที่สองของฟอร์มขึ้นเฉพาะ Transfer หรือเมื่อเปิดจากปุ่ม "จ่าย" ในหน้าหนี้สิน (ตัวแปร `txPayCard`) —
  เลือกประเภท Debt ในฟอร์มเองมีช่องบัญชีเดียว บันทึกได้แค่ "ธนาคาร −x" ยอดบัตรไม่ลด
- ยืนยันกับ main (v84): เลือก Debt → ช่องบัญชีที่สองไม่ขึ้น

## แก้
- ประเภท **Debt** มีช่อง **"ตัดยอดบัตรเครดิต / สินเชื่อ (ช่องนี้เป็นบวก)"** เสมอ
  - ค่าแรก "— ไม่ตัดยอดบัตร/สินเชื่อ" (ค่าตั้งต้น — ค่างวดที่ไม่มีคอลัมน์ในชีต เช่น มอเตอร์ไซค์ ยังลงแบบเดิมได้)
  - บัตรเครดิต/สินเชื่อขึ้นก่อน (`isCreditAccount` · Loan · ยอดติดลบ — นิยามเดียวกับหน้าบัญชี) ตามด้วยบัญชีอื่น
  - เลือกบัตร → เขียน ธนาคาร −x · บัตร +x ในแถวเดียว · ช่อง "บัญชี" เปลี่ยนชื่อเป็น "จ่ายจากบัญชี"
  - หมวด/รายละเอียดเติมให้ตามแบบที่เคยลง: แท็บ Debts (`payCat`) → แถวจ่ายบัตรนี้ครั้งล่าสุด → "Clear Debt <บัตร>" ·
    เติมเฉพาะช่องที่ว่างหรือที่ฟอร์มเติมเอง (ไม่ทับที่พิมพ์) — หมวดตรงกับหน้าหนี้สิน ความคืบหน้าการจ่ายจึงนับถูก
  - ตัวอย่างก่อนบันทึกบอกยอดบัตรก่อน → หลังบันทึก
  - สถานะ "จ่ายบัตร" อยู่ที่ค่าของช่องนั้น (`txIsCardPay()`) แทนตัวแปร `txPayCard` — เปิดแก้แถวจ่ายบัตรเดิม / กด "จ่าย" จากหน้าหนี้สิน ใช้ทางเดียวกัน
- ช่อง "บัญชี" แบ่งกลุ่ม **บัญชีเงินฝาก / e-wallet** กับ **บัตรเครดิต / สินเชื่อ** — รายจ่ายที่รูดบัตร / เงินคืนเข้าบัตร เลือกบัตรได้ง่ายขึ้น
- ตัวอย่างก่อนบันทึก: รายจ่ายที่ยังไม่กรอกยอดขึ้น "−0.00" (เดิม "+0.00")
- ข้อความในฟอร์ม (หัวข้อ · ปุ่ม · ป้ายช่อง · ข้อความเตือน) สองภาษา

## ตรวจแล้ว
- Chromium + ชีตจำลอง (บัตร SCB Up2ME · KBank Line Point · Rabbit Card) + Sheets API จำลองที่เก็บคำขอเขียน:
  - Debt + เลือก SCB Up2ME 7,000 → เขียน `D=Debt · E=Clear Debt SCB Up2ME Credit Card · G(SCB)=−7000 · K(Up2ME)=+7000`
  - Debt ไม่ตัดยอด (ค่างวด) → เขียนเฉพาะ `G=−3200`
  - เปิดแก้แถวจ่ายบัตรเดิม → ช่องบัตร = SCB Up2ME · บันทึกแล้วยังเขียนช่องบัตร +7,480.81 (ไม่ถูกล้าง)
  - เปิดแก้ค่างวด → "ไม่ตัดยอด" · Transfer ยังเป็น "โอนเข้าบัญชี" · กด "จ่าย" จากหน้าหนี้สินยังเลือกบัตรให้
  - รายจ่ายรูดบัตร → `K=−120`
  - หมวดที่พิมพ์เองไม่ถูกทับเมื่อเปลี่ยนบัตร
  - 1366 ไทย · 375 อังกฤษ ไม่ล้นจอ · ไม่มี error/warning
- JS 18 ชุดผ่าน · inline script parse ผ่าน
