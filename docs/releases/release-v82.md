# v82 — หน้าปันผล: กราฟ Yield / Payout (แบบ Snowball)

คำขอ (2026-10-31): ปรับหน้าปันผลตามภาพ Snowball ที่แนบ — **รอบนี้ทำข้อ 1 ก่อน** (ผู้ใช้จะมาปรับต่อ):
กราฟ Yield/Payout มี dropdown ไม่มีกรอบ 2 ตัว — ค่าที่แสดง **Yield (%) / Annual Payout (บาท)** และการจัดกลุ่ม
**Holdings** (รายตัว) · **Categories** (ประเภทสินทรัพย์ เช่น fund, stock) · **Sectors** (อุตสาหกรรม เช่น Walmart = ค้าปลีก)

## ตัวเลข
| | นิยาม |
|---|---|
| ปันผลต่อปี (บาท) รายตัว | คาดการณ์ 12 เดือนข้างหน้า (`dividendCalendar().byTicker` — ชุดเดียวกับการ์ด "คาดการณ์" ที่มีอยู่ · ก่อนหักภาษี) · ตัวที่ไม่มีข้อมูลคาดการณ์ใน `fundamentals.json` → ยอดที่ได้รับจริง 12 เดือนล่าสุดจาก Asset_Tracker |
| Yield (แท่ง) | ปันผลต่อปี ÷ มูลค่าวันนี้ |
| Yield on cost (ขีด) | ปันผลต่อปี ÷ ต้นทุน (WACC × จำนวนที่ถือ) — เหมือนขีดในภาพ Snowball |
| Holdings | เฉพาะตัวที่มีปันผล |
| Categories / Sectors | หารด้วยมูลค่า/ต้นทุน **ทั้งกลุ่ม** รวมตัวที่ไม่จ่าย (= yield จริงของเงินก้อนนั้น) · แสดงเฉพาะกลุ่มที่มีปันผล |
| Sectors มาจาก | ช่อง **Industry** ใน Asset_Tracker (`fundamentals.json` ไม่มี sector) · ว่าง/"—" → "ไม่ระบุอุตสาหกรรม" |
| เรียง | มาก → น้อยตามค่าที่เลือก · ตัวที่ไม่มีราคา (Yield คิดไม่ได้) ไว้ท้าย แต่ยังเห็นยอดบาท |

แถวสรุปเหนือกราฟ: Yield · Yield on cost · ปันผลต่อปี + ต่อเดือน (ทั้งพอร์ต) · tooltip รายแท่ง: ปันผลต่อปี + ที่มา (คาดการณ์/ได้รับจริง) · มูลค่า · Yield · YOC · กลุ่ม: รายชื่อตัวที่จ่าย ·
หมายเหตุใต้กราฟบอกนิยามและจำนวนตัวที่ใช้ยอดได้รับจริงแทนคาดการณ์

## โค้ด
- `shared.js`: `dividendCalendar` คืน `byTicker` เพิ่ม (ผลรวม = `annual` เสมอ) · `dividendYieldView(holdings, fwdByTk, rec12ByTk, by, sortBy)` · `DIV_NO_SECTOR`
- `index.html`: `_dvCal()` คำนวณปฏิทินปันผลครั้งเดียวต่อการ render (ตัวติดตามปันผล + กราฟใช้ร่วม — เดิมอยู่ใน `renderDividendTracker`) · `renderDvYield()` ·
  การ์ด `.dv-yp` ต่อจากการ์ด "ประวัติที่ได้รับจริง" · dropdown ไม่มีกรอบ (`.dv-sel` + ลูกศร CSS · `field-sizing:content` ให้กว้างเท่าข้อความ) · จำค่าที่เลือกใน `finOS_dvYp` (เฉพาะเครื่อง) ·
  กราฟแสดงได้แม้ชีตยังไม่มีแถว Dividend Payout (ใช้คาดการณ์)
- build `v82`

## รอบ 2 (2026-10-31) — ส่วนที่เหลือจากภาพ Snowball ตามลำดับในภาพ

คำขอ: "ปรับเลย ให้เป็นกราฟด้านล่างแสดงต่อมา" — ทำทุกส่วนที่เหลือในภาพต่อจาก Yield / Payout

| การ์ด | ข้อมูล | dropdown |
|---|---|---|
| **Passive income diversification** | โดนัท + รายการแท่ง % (฿) ของปันผลต่อปี — ชุดเดียวกับ Yield/Payout · รายตัวมีชื่อเต็มจาก fundamentals | Holdings / Categories / Sectors |
| **Average annual growth** | ปันผลต่อหุ้นโตเฉลี่ยต่อปี (CAGR) — `divGrowthRate`: เฉพาะปีที่จ่ายครบ (ก่อนปีนี้ · จำนวนครั้ง ≥ ฐานนิยม) ย้อนสูงสุด 5 ปี · ครบไม่ถึง 2 ปี → ไม่แสดง (บอกจำนวน) · กลุ่ม = ถ่วงด้วยปันผลต่อปี | Holdings / Categories / Sectors |
| **Future payments** | 12 เดือนข้างหน้า · ต่อเดือน · Yield คาดการณ์ · ยังไม่ได้รับ + กราฟซ้อน ได้รับแล้ว/ประกาศแล้ว/ประมาณการ — **ย้ายมาจากตัวติดตามปันผล** (เดิมอยู่เหนือปฏิทิน) | — |
| **Dividends received** (ช่วงเวลา) | ยอดได้รับจริงจาก Asset_Tracker · รวม + เฉลี่ย/เดือน — `dividendsReceivedSeries` | ช่วง: ทั้งหมด · ปีนี้ถึงวันนี้ · 12 เดือนล่าสุด (ค่าเริ่มต้น) · รายปี · ความละเอียด: รายเดือน / รายปี (รายปี = ทุกปี ซ่อนตัวเลือกช่วง) |
| **Dividends received** (รายตัว) | ยอดได้รับจริงทั้งหมด รวมตัวที่ขายแล้ว · 15 อันดับ ที่เหลือรวม "อื่น ๆ" — `dividendsReceivedBy` | Holdings / Categories / Sectors |
| **Dividend growth** | ได้รับจริงแต่ละเดือน (ม.ค.–ธ.ค.) เทียบ 3 ปีล่าสุด — `dividendMonthMatrix` | — |

- **ลบ**: กราฟ "ปันผลรายเดือน" (18 เดือน) และกล่อง "ปันผลรายปี" — Dividends received ครอบคลุมทั้งสองแบบแล้ว
- คงไว้: การ์ดประวัติที่ได้รับจริงด้านบน · ปฏิทินปันผลรายเดือน (หัวข้อใหม่ "ปฏิทินปันผล 12 เดือนข้างหน้า") · ตารางผู้จ่ายปันผล
- ค่าที่เลือกใน dropdown ทุกการ์ดเก็บใน `finOS_dvUi` (เฉพาะเครื่อง · แทน `finOS_dvYp` ของรอบแรกซึ่งยังไม่เคย deploy)
- **แก้บั๊กของรอบแรก**: `renderDividendTracker` ยังอ้าง `usd` ที่ย้ายเข้า `_dvCal` แล้ว → ReferenceError ปฏิทินปันผลหายทั้งก้อน (ถูกกลืนใน try/catch เลยไม่ขึ้นเป็น page error · เทสต์เบราว์เซอร์รอบแรกเลยไม่เห็น) — `_dvCal` คืน `usd` · หมายเหตุย้ายไปการ์ด Future payments · เทสต์เบราว์เซอร์จับ `console.warn('[div] …')` ด้วยแล้ว
- ลบ CSS ของบล็อกบนตัวติดตามปันผลที่ไม่มีใครใช้แล้ว (`.dvt-top/.dvt-inc/.dvt-big/.dvt-box/.dvt-row/…`)
