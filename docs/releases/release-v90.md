# v90 — ฟอร์มบนมือถือ: ช่องวันที่ทับช่องข้าง ๆ

ผู้ใช้เจอ (2026-11-12 · iPhone): ฟอร์มจากปุ่ม + (เพิ่มรายการ · จ่ายบัตรเครดิต · โอน) ช่อง "วันที่" ล้นไปทับช่อง "ประเภท"

## สาเหตุ
- iOS แสดงช่องวันที่ตามปฏิทินของเครื่อง ("12 Nov BE 2569") และให้ช่องกว้าง**ขั้นต่ำเท่าข้อความข้างใน** ไม่ยอมหดตาม `width:100%`
- บนมือถือช่องกรอกถูกตั้งเป็น 16px (กัน iOS ซูมตอนแตะ) ข้อความวันที่จึงกว้างเกินครึ่งฟอร์ม
- แถวสองคอลัมน์ใช้ `grid-template-columns:1fr 1fr` — คอลัมน์ `1fr` หดต่ำกว่าเนื้อหาไม่ได้ → ช่องวันที่ล้นไปทับช่องข้าง
- Chrome หดช่องวันที่ให้เอง จึงไม่เห็นตอนทดสอบในเบราว์เซอร์ (ทดสอบบน iPhone จริงไม่ได้)

## แก้ (CSS ล้วน)
- แถวฟอร์มทุกแบบ (`.tx-g2` · `.gf-row` · `.dbf-g2` · `.srf-grid` · `.at-g3` · `.rc-top`) ใช้คอลัมน์ `minmax(0,1fr)` · ลูกของ grid และช่องกรอก `min-width:0`
- ช่องวันที่/เดือนทุกช่องถอดหน้าตาแบบระบบ (`appearance:none`) ให้หดตามคอลัมน์ · ข้อความชิดซ้าย · สูงเท่าช่องอื่น
  (ทุกอุปกรณ์ ไม่ผูกกับ media จอสัมผัส — iPad ต่อแทร็กแพดก็ต้องหด · ทุกช่องมีกรอบ/พื้นของแอปอยู่แล้ว เดสก์ท็อปหน้าตาเหมือนเดิม ยังมีปุ่มปฏิทิน)
- **มือถือแนวตั้ง (≤ 480px)**: ครึ่งคอลัมน์แคบเกินจะเห็นวันที่ครบ (ถูกตัดท้าย) → แถวที่มีช่องวันที่เป็นคอลัมน์เดียว (วันที่เต็มแถว · ประเภทอยู่บรรทัดถัดไป) ·
  แถวอื่น (บัญชี + จำนวนเงิน) ยังสองคอลัมน์ · เบราว์เซอร์ที่ไม่รู้จัก `:has()` ได้สองคอลัมน์ที่ไม่ทับกัน
- ฟอร์มที่ได้ผล: รายรับ-รายจ่าย · จ่ายบัตร · โอน · ลงทุน · เอกสาร · หนี้ · ยอดจริงธนาคาร · รายการราคา/ประกัน · เป้าหมาย (Deadline · Track from)
