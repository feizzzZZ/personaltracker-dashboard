## ข้อสังเกตทางเทคนิคที่เจอรอบนี้ (กันพลาดรอบหน้า)

- ราคา/สัญญาณดิบจาก market-data.json อยู่ใน `loadActions()` (`finOS_actions`) — `loadMarketData()` เก็บแค่ macro ที่ merge แล้ว
- `gsInit()` เป็น async แล้ว และไม่ทำงานถ้า vault ล็อกอยู่ (`authDataAllowed()`) — โค้ดใหม่ที่ดึง/บันทึกข้อมูลต้องผ่านด่านนี้
- cache ข้อมูลและ token: มีรหัสผ่าน → `Vault.setItem/getItem` (`finOS_enc:*`) · ไม่มี → localStorage เหมือนเดิม
- ตอนทดสอบในเครื่อง service worker ชื่อ cache เดิม (เช่น v74) เสิร์ฟ `shared.js` เก่าค้าง → ล้าง SW/caches ก่อนทดสอบหน้าเดิมซ้ำ (production ไม่โดนเพราะชื่อ cache เปลี่ยนทุกเวอร์ชัน)
- Python ในเครื่องเป็น 3.9 — สคริปต์ใช้ `X | None` ต้องรันด้วย `python3.12`
- (v76) บล็อกธีม v74 (บรรทัด ~1500+ ของ `index.html`) มีกฎ **นอก media query** ที่ทับกฎมือถือเดิมได้ เช่น `.grp-tabs{padding:0 32px}` เคยลบ padding safe-area ของ v66 → แก้สไตล์มือถือให้ใส่ใน `@media(max-width:768px)` ของบล็อก v74 (หลังกฎเหล่านั้น)
