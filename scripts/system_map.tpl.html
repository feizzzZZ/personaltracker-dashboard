Overview: who talks to whom

The app has no server of its own. Your phone reads and writes Google Sheets directly. Market data comes from GitHub, which refreshes it on a schedule (and also reads your sheet, read-only, to write the alert summaries). Crypto balances come through a Cloudflare Worker.

A day in the system

Jobs that run on their own, in Thai time. You don't need to press anything.

From opening the app to a saved entry

What happens between tapping the app icon and a new row appearing in your sheet.

  1. Open the app

    The app files load instantly from the copy on your device, then a new version is checked on GitHub Pages in the background.

  2. Unlock

    Enter this device's password to decrypt the stored data and your Google token.

  3. Sync

    Reads 10 tabs from your sheet at the same time, and the market-data files from GitHub.

  4. Calculate

    Account balances (checked against Reconcile) · average cost and profit · dividends · debts · goals.

  5. Press +

    Pick one of 13 forms grouped Money · Invest · Other and fill it in. The form suggests values you use often.

  6. Save

    If the same entry is already in the sheet you are asked to press Save again. An expiring Google session is renewed first, and your entries stay in the form. The tab is read again right before writing, so no other row or formula column is touched.

  7. Confirm

    The app re-reads your sheet (market data is left as is) and shows “✓ Saved to the sheet”.

Shipping a change

The path every change takes, from asking for it to seeing it on your phone.

  1. Ask Claude

    Describe the problem or what you want, with a screenshot if you have one.

  2. Fix and test

    Claude changes the code, runs the tests, tries it in a browser against a mock sheet, then opens a pull request. GitHub runs every test again on the pull request.

  3. You merge

    Press Merge on the pull request once its checks are green.

  4. Site updates

    GitHub Pages serves the new code within about 1–2 minutes.

  5. Reopen the app

    Close and reopen the app. It sees the new version (e.g. v92) and loads the new files.

Two exceptions Worker changes (cloudflare-worker/autobot/, js/autobot.js, js/liveport.js): deployed by GitHub after the merge once the CLOUDFLARE_API_TOKEN secret is set. Until then, deploy them yourself with npx wrangler deploy in that folder. Pipeline changes (scripts/ · .github/workflows/): they take effect at the next scheduled run, or press Run workflow in the Actions tab.

Where data and keys live

There is no central server holding your financial data. Each thing lives only in its own place.

YOUR GOOGLE SHEETS

The original financial data

  • Income and expenses · portfolio · prices
  • Debts · insurance · bank balances
  • Document list (links to Drive)
  • Weekly backup copies in your Drive (optional)
THIS DEVICE (PHONE / COMPUTER)

Settings and a local copy

  • Client ID · Spreadsheet ID
  • Google token and data copy (encrypted with your password)
  • Budgets · goals · theme · language
GITHUB (PUBLIC REPO)

Code and market data

  • App and pipeline code
  • Market prices (none of your balances)
  • Notification inbox, encrypted with NOTIFY_KEY
  • Secrets: GOOGLE_SA_KEY · GS_SHEET_ID · NOTIFY_KEY · VAPID · PUSH_SUBSCRIPTIONS · LINE · SEC_USER_AGENT · CLOUDFLARE_API_TOKEN (Worker deploy)
CLOUDFLARE WORKER

Bot and live portfolio

  • Read-only Binance key · BOT_TOKEN
  • Bot rules · paper portfolio
  • MetaMask wallet addresses (public; never a seed phrase)
